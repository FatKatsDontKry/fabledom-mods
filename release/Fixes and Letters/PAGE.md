# Page text (GitHub release / Nexus description)

**Fabledom Fixes and Letters** (Fixes 0.5.1, Letters 0.2.1; with the optional Performance 0.4.0 and Sickness 0.1.0; Sickness off by default)

Four mods in one download, each its own DLL with its own config, so you can run any of them alone. **Fixes** repairs things the base game gets wrong, mostly in large kingdoms: carried goods deleted when a task is cut off, deliveries that overflow a full store, phantom tenants who count toward the population while holding no bed, the global sickness debuff that never applied, fablings fallen through the world, sick fablings left standing in a hospital after losing their bed, and the Marketplace, whose slots can now be emptied one at a time and whose marketeers can be dismissed without losing the wrong good. It also brings the late-game performance work that keeps a 2,000-fabling kingdom playable: behaviour trees in round-robin slices, and unemployed fablings dormant away from the camera. **Letters** puts the family and sister letter chains, which the base game designed but never actually chained, back in working order, and fixes the bad-letter draw and the late-game letter pacing. **Performance** and **Sickness** are optional extras: more frame time for very large kingdoms, and sickness that scales with population so hospitals matter again.

Works on existing saves. Made and tested by one person; please report anything odd at https://github.com/FatKatsDontKry/fabledom-mods/issues with your `BepInEx/LogOutput.log` attached.

**Requires** BepInEx 5 (x64, 5.4.x). **Install:** unzip into `Fabledom/BepInEx/plugins/`. Full instructions, what every config line does, and known things are in the README inside the zip.

**Download:** `Fixes-and-Letters-0.5.1.zip`
